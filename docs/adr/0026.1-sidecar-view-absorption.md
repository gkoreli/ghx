# 0026.1. `ghx sidecar view` — Viewer Absorption

## Status

Accepted and implemented. Executes row 1 of the ADR-0026 absorption
watchlist (otel-desktop-viewer, HIGH impact / LOW effort, "M6 polish;
near-term"): the strongest competitive move is not to beat a tool but to
consume it under the hood so it disappears into the product (NORTH_STAR
"Swallow the tools"). Pattern source: Inspect AI's `inspect view` — one
command from committed eval artifacts to a browsable UI.

## Context

Every session directory under `~/.ghx/sessions/<slug>/` is a spec-exact
OTLP bundle (ADR-0022 D2/D3: `traces.jsonl`, `logs.jsonl`,
`metrics.jsonl`, `reports/`). Viewing one required the ADR-0018 "Live
validation" curl recipe: start `otel-desktop-viewer` by hand, then
shell-loop each JSONL line into `localhost:4318/v1/<kind>`. Proven live
(100% OTLP acceptance, ADR-0018), but a recipe is friction — the
visibility tenet ("traces for everything, viewable by humans") deserves
one command.

## Decision

`ghx sidecar view [session]` — spawn the viewer, replay the session's
artifacts, keep the viewer foreground until Ctrl-C. Fixed semantics:

- No argument = most recent session (meta `updatedAt`, falling back to
  `traces.jsonl` mtime for artifact-only dirs). Session root respects
  `GHX_HOME` and the legacy `~/.ghx-sidecar` read-fallback by reusing
  `LoadConfig().SessionsDir` (config.go `activeRoot`, ADR-0022 D3).
- `--list` prints sessions with turn/report counts and trace presence
  instead of launching; `--port` sets the viewer UI port (default 8000).
- Missing `traces.jsonl` errors clearly and names the sessions that DO
  have traces.
- Viewer discovery is PATH-only. If absent, print the exact install
  command (`go install github.com/CtrlSpice/otel-desktop-viewer@latest`)
  and exit nonzero. **Rejected:** vendoring or auto-installing the viewer
  — it stays an upstream tool we spawn, credited openly (open-source
  leverage tenet: steal the workflow, not the code).
- Replay is the ADR-0018 recipe verbatim, in Go: wait for the OTLP HTTP
  ingest on `localhost:4318`, then POST each JSONL line to
  `/v1/<kind>` with `Content-Type: application/json`. No parsing, no
  re-encoding — the artifacts are already spec OTLP JSON, and mutating
  them on the way through would violate the "official formats exactly"
  rule.

## Implementation notes

- `internal/sidecar/view.go` — testable core: `ListViewSessions` /
  `ResolveViewSession` (session resolution + friendly errors),
  `FormatViewSessions` (`--list` table), `WaitForIngest` (poll until the
  ingest listener answers), `ReplayFile` / `ReplaySession` (line-by-line
  POST loop; non-2xx aborts with file + line number).
- `internal/cli/sidecar_view.go` — thin cobra command; child-process
  lifecycle via `exec.CommandContext` + `signal.NotifyContext`, with
  `cmd.Cancel` sending SIGINT and `WaitDelay` force-killing a lingering
  viewer. Ctrl-C is treated as clean exit, not error.
- Beyond the minimum: `logs.jsonl` and `metrics.jsonl` are replayed too
  when present (traces remain mandatory) — the recipe always replayed all
  three kinds, and content-capture logs are half the visibility story.
- Artifact-only directories (traces without `meta.json`) stay viewable;
  `ListSessions` would drop them, so `ListViewSessions` scans
  independently.
- The OTLP ingest port stays at the viewer default 4318; only the UI port
  is configurable. Known sharp edge: if something else already listens on
  4318, `WaitForIngest` can succeed against the foreign listener. Accepted
  for now — the failure mode is visible (viewer shows nothing) and rare on
  a dev machine.
- `sidecar.ArtifactsHint` (shown by `ghx sidecar doctor`) now points at
  `ghx sidecar view` instead of the curl recipe; README gains a Sidecar
  section documenting the command.
- Tests (`internal/sidecar/view_test.go`): session resolution (named,
  default-most-recent, no-traces error naming alternatives), `--list`
  formatting, and the replay POST loop against an `httptest` server
  standing in for the viewer ingest (asserts method, `/v1/traces` path,
  content type, per-line bodies, blank-line skipping, non-2xx abort). The
  real viewer binary is never required by tests.

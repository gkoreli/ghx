# 0033.2. agentSettingSources — opt-in host settings for enterprise Claude installs

## Status

Accepted (orchestrator, 2026-07-06). Follow-up to ADR-0033.1; closes the
founder's work-laptop arc with a config knob instead of a hand-written
wrapper script.

## Problem

Sidecar sessions always send `settingSources: []` (full isolation — the
ADR-0016.3 posture: no host CLAUDE.md/settings leak into the subject).
Founder isolation (2026-07-06) proved that posture *breaks* enterprise
Claude installs at the binary level: toolbox-wrapped Claude Code resolves
Bedrock model aliases (`modelOverrides`) and its credential-export hook
from `~/.claude/settings.json`; with that file blocked, the native binary
hangs indefinitely at prompt time in ACP/streaming mode (the `-p` codepath
errors cleanly — the hang is an upstream defect, reported separately). The
wrapper injects env *before* exec, but the binary re-reads settings
*after* — env passthrough (ADR-0033.1) cannot fix that half.

## Decision

`Config.AgentSettingSources []string` (`agentSettingSources` in
`~/.ghx/config.json`): values from {`user`, `project`, `local`},
validated at load (unknown values warn and drop — a typo degrades loudly
to isolation, never silently widens it). Nil/absent keeps today's `[]`.
Non-nil is forwarded verbatim in `_meta.claudeCode.options`. The field
joins the daemon config digest so a warm daemon restarts on change.

Isolation trade-off is the user's explicit, documented choice: `["user"]`
lets host user settings (env, hooks, model overrides) apply to sidecar
sessions. Eval runs construct their own `Config` and never read the user
config file — the measurement posture is unchanged.

## Evidence

- `internal/sidecar/config.go` — field + `validAgentSettingSources`.
- `internal/sidecar/session_options.go` — `BuildSessionMeta` parameter;
  nil → `[]` on the wire (wire-shape tests unchanged for the default).
- `internal/sidecar/daemon.go` — digest row.
- Tests: `TestBuildSessionMetaSettingSourcesOptIn`,
  `TestValidAgentSettingSources`; existing byte-equality steering tests
  pin the default posture.

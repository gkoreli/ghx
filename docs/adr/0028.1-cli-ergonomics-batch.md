# 0028.1. CLI Ergonomics Batch 1

## Status

Accepted 2026-07-06. Evidence chain: agent-usage mining
(`docs/evals/mining-2026-07-06/CLI-FINDINGS.md` — 8 defects, counts +
episode refs, cross-family miner) refined by prior-art research
(ADR-0028, 16 sources). Agents are ghx's users; their traces are the
usage study. Honesty note (NORTH_STAR workstream A): CLI gains lift the
`ghx` baseline and the sidecar alike — the eval isolates the sidecar's
*additional* value, so this batch is product work, not gate gaming.

## Decisions (sequenced as ADR-0028 recommends)

### D1. `--version` works (defect 8, 30 observed failures)

Cobra `Version` field on the root command; `ghx --version` and
`ghx version` both answer.

### D2. Suggestions that stop lying (defect 5's sharp edge)

`grep` currently suggests `tree` (uncurated Levenshtein). Add
`SuggestFor` curation so `ghx grep` suggests `search` / `read --grep`,
and audit other high-traffic misses the same way.

### D3. Flag errors teach the correct invocation (defect 3, 28 failures + 21 flail runs)

Cobra `SetFlagErrorFunc`: unknown-flag errors name the nearest real flag
AND show one complete corrected example (`unknown flag --start; use
--lines START-END, e.g. ghx read owner/repo main.go --lines 40-80`).
Additionally the two most-guessed families become **hidden aliases**
(`--start N --end M`, `--offset N --limit M` → normalized to `--lines`):
one documented form per clig.dev, zero-friction acceptance of structural
guesses per the trace evidence. Hidden means absent from help, present in
the parser.

### D4. Examples in every command's help (ADR-0028 addition)

Every subcommand's `--help` gets an `Examples:` block with 2-3 real
invocations (Cobra `Example` field). `ghx explore --help` currently has
zero.

### D5. Budgeted output with escalation (defects 1, 6, 7)

One shared `--budget CHARS` dial (default per command, generous but
bounded) + `--full` escape across `explore`, `read`, `search`:

- `explore`: compact orientation by default (README summary, capped
  entries, suggested subpaths); current output behind `--full`.
- `read` over threshold without `--map`/`--lines`/`--grep`: emit the
  structural map + line anchors and a header hint naming the narrowing
  flags, not the whole file.
- `search`: bounded results with a "narrow with --lang/--glob" hint;
  auto-quote GitHub query characters that currently produce parse fatals.
- Every truncation names the flag that lifts it (truncation as teacher).

### D6. `ghx grep` (defect 5) and `ghx search <repo> <query>` simple form (defect 7)

`ghx grep <repo> <pattern> [--glob] [--path] [--limit]` with
ripgrep-mirroring flag names (muscle-memory transfer); `search` gains the
repo-first simple form, keeping the raw GitHub-query form as advanced
mode.

### D7. Semantic exit codes (ADR-0028 addition)

Distinguish "no results" from "bad invocation" from "upstream/API
failure" — agents branch on exit codes when they can.

### Deferred to batch 2 (needs its own design pass)

`ghx inspect <repo> <query>` (defect 4 — ranked files + maps + bounded
snippets in one budgeted call). Highest-value, largest surface; design
against aider repomap ranking + ADR-0024 tier-2 work, not rushed here.

## Verification

Unit tests per decision (alias normalization, error-text goldens,
budget truncation + hint presence, exit codes). Live: after merge, a
random 2-3-cell spot check (CLAUDE.md routing) watching for the defect
signatures disappearing from fresh traces (no `--start` failures, no
`grep`→`tree`, shrinking explore output). The full defect-signature
comparison against the mining baseline happens at the next full-rigor
run — pre-registered here as the A2 success measure.

## Considered and rejected

- **Documented (non-hidden) alias proliferation** — clig.dev one-name
  rule; help stays single-truth (ADR-0028's core disagreement with the
  miner, adopted).
- **Micro-flags for explore** (`--files-limit`, `--readme-lines`) — one
  `--budget` dial per the jj/aider/semgrep convergent pattern.
- **Shipping `inspect` in this batch** — see Deferred.

## Implementation Notes

Implemented on branch `codex-cli-ergonomics-batch1` in July 2026.

- D1 landed through Cobra's root `Version` field while preserving the
  existing `ghx version` subcommand.
- D2 changed shape because `ghx grep` now exists as a real command in this
  batch. The misleading `grep` to `tree` path is removed by the command
  itself; explicit `SuggestFor` curation remains on high-traffic adjacent
  guesses (`search` for `find`, `grep` for `rg`).
- D3 uses a root `SetFlagErrorFunc` plus hidden `read` aliases. The canonical
  help and examples stay on `--lines START-END`; `--start/--end` and
  `--offset/--limit` are parser-only aliases. `--offset N --limit M` maps to
  `N-(N+M-1)`, matching the common offset/count mental model.
- D4 added Cobra `Example` blocks across the classic CLI, MCP/server command,
  and sidecar command tree so every visible command has copyable invocations.
- D5 is implemented as a CLI presentation budget. `explore` prints compact
  orientation by default and keeps complete legacy output behind `--full`.
  `read` fetches the requested blob, but if the content exceeds `--budget`
  with no `--map`, `--lines`, or `--grep`, it returns a structural map plus a
  narrowing hint. `search` accepts the shared budget and marks/hints truncated
  result sets.
- D6 adds `ghx grep <repo> <pattern>` with `--glob`, `--path`, and `--limit`,
  backed by GitHub code search. `search` now accepts both raw advanced queries
  and repo-first `ghx search <repo> <query>` form, auto-quoting repo-first
  query text that contains GitHub search syntax-sensitive characters.
- D7 adds semantic exit-code plumbing at the CLI boundary: `0` ok, `1` no
  results, `2` bad invocation, `3` upstream/API failure. Command handlers now
  return typed errors instead of exiting directly for classic no-result and
  upstream cases.

Scoped follow-up: `grep --glob` is translated to a GitHub `path:` qualifier,
not a local ripgrep engine over an expanded tree. That is sufficient for the
batch's guessable command/flag surface, but exact doublestar glob semantics can
be tightened in a later search-backend pass if traces show mismatch.

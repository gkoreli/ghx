# ADR-0024.4. Runtime-Owned Escalation

## Status

Proposed. Research grounding: `docs/research/m7-tier2-escalation.md`
(§1.2 precise gap, §2 D-candidates, §8 evidence appendix). Advances NORTH_STAR
**M7** / workstream **A3+B9**: the tier-2 substrate and policy engine are
shipped (ADR-0024.1/.2); this completes the "sidecar-decided" half.

## Context

Verified at HEAD `719cb29`:

1. **Post-hoc, not pre-gating.** The runtime "records and reconciles rather
   than intercepts" (`internal/sidecar/tier.go:16-18`, ADR-0024.2 D3 honest
   deviation); nothing blocks an ungranted or unjustified escalation before it
   happens.
2. **Three of seven signals are never set**
   (`remote.symbol_absent_after_maps`, `remote.candidate_ambiguous`,
   `remote.import_chain_invisible`) — they need semantic judgment the v1
   runtime cannot recompute (ADR-0024.2 D2).
3. **No eval gate measures the policy.** `internal/sidecar/evals/gates.go`
   has no tier reference; the M4 verdict measured profiles, not escalation.
4. **No cache user surface.** TTL+LRU eviction exists
   (`internal/sidecar/tier2/cache.go:61-77`) but `ghx cache ls/clean` was
   deferred (ADR-0024.1 open question).

Grant plumbing already exists end-to-end (`--local` →
`AskRequest.AllowedBackends` → daemon JSON-RPC), so only the decision layer is
missing.

## Decision

- **D1 — Agent-declared observations, trace-cross-validated.** The agent may
  declare semantic signals mid-turn (structured `tier.observe` command or
  report-block field); a declaration is accepted only when consistent with the
  turn's wire traces (`internal/sidecar/ledger.go` extraction). Divergence is
  recorded as an anomaly. The policy stays recomputable.
- **D2 — Pre-hoc gating on both paths.** Before a `local:*` command executes,
  the runtime evaluates the recorded policy; blocked commands get an
  affordance error (pairs with ADR-0034.1) and a `tier.decision` record with
  `decision=blocked`. Identical behavior on daemonless (`AskWithTurnRunner`)
  and daemon paths, wire-pinned like the H8 meta fix.
- **D3 — Policy-precision eval gate.** Pre-registered gate over escalated
  episodes: escalated tasks must not regress correctness (non-inferiority per
  ADR-0032.1 style) and fired-signal sets must beat a no-escalation
  counterfactual. Reuses ADR-0025 D1/D2 run economics; threshold fixed from
  the fixbatch distribution before any citable run.
- **D4 — Cache surface.** `ghx cache ls/clean` over existing eviction;
  discharges the ADR-0024.1 open question.

Rejected alternatives: keep post-hoc forever (bookkeeping, dead signals,
unmeasured); MCP-expose codemap to the main agent (violates P3 zero-CLI);
main-agent-driven clone (silent magic).

## Consequences

- "Which tier answered and why" becomes fully auditable pre-hoc; M7/B9 can
  honestly flip to done after D3's first citable run.
- Risks: gamed declarations (mitigated by trace cross-validation), added run
  economics cost (mitigated by stopping + baseline reuse), two-path divergence
  (mitigated by parity tests).
- Composes with B7 routing (per-turn decisions inside routed sessions) and
  gives M8 anticipation a clean pre-evaluation hook.

# 0022.1. Live Turn Log — realtime per-session activity stream

## Decision

Accepted and implemented (2026-07-06); extends the shared visibility runtime
(ADR-0022) with a realtime surface.

Today all session artifacts (traces.jsonl / logs.jsonl / metrics.jsonl,
`emitTurnArtifacts` in `internal/sidecar/emit.go`) flush only at Ask exit;
during a multi-minute turn the session dir shows nothing live except
agent-stderr.log. Founder requirement (Goga, 2026-07-06): events must append
to a file AS THEY HAPPEN inside the ACP runner.

- **`LiveLog`** (`internal/sidecar/live.go`): a concurrency-safe, append-only
  NDJSON writer for `<sessionDir>/live.jsonl`. One JSON object per line:
  `{"ts":"<RFC3339Nano UTC>","event":"<type>", ...fields}`. Best-effort
  everywhere — empty path, open failure, or write failure degrades to a no-op
  (one stderr warning); a live-log failure never fails or slows a turn.
- **ACP client events** (`denyClient.SessionUpdate`, `internal/sidecar/acp.go`),
  written as notifications arrive: `text` / `thought`
  (`{"chars":N,"textExcerpt":<=256 bytes}`), `tool.call`
  (`{"id","title","kind","status"}`), `tool.update`
  (`{"id","status"?,"outputSize":N}`). LoadSession history replay is skipped —
  live.jsonl records only new activity.
- **Runtime events** (`askWithTurnRunner`, `internal/sidecar/runtime.go`):
  `turn.started` (`{"session","repo","question"}`) right before the primary
  turn; `turn.completed` (`{"ok","error"?,"tools":N,"chars":N}`) via defer on
  every exit path.
- **Wire-through**: `RunTurnOptions.LiveLogPath` (next to `AgentStderrPath`),
  set from the exported `LiveLogPath(sessionsDir, session)` helper on the
  primary turn, the max-turns wrap-up, and report retries. Both the one-shot
  path (`RunTurnWithOptions`) and the warm daemon worker
  (`daemon_worker.go`, opened per turn) construct the client's `LiveLog` from
  it. Append mode makes the concurrent runtime/client writers safe.

## Boundaries

- traces.jsonl / logs.jsonl / metrics.jsonl semantics are unchanged:
  spec-exact OTLP, written at end of turn (ADR-0022). live.jsonl is a progress
  surface, not an audit artifact — full text and tool traces still land in the
  report and traces.
- No secrets: live events carry only the fields above; the question text
  already lands in ledger/report artifacts.

## Evidence

Unit tests in `internal/sidecar/live_test.go` (NDJSON validity, disabled
no-op, 256-byte excerpt cap); e2e in `TestDaemonAskReusesWarmMockAgent`
(`daemon_test.go`): after a daemon Ask, live.jsonl holds turn.started,
activity, and turn.completed ok=true lines, all valid JSON.

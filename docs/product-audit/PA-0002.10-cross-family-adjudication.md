## Biggest disagreement (accepted — corrections folded)

> "The audit's 'clean drop-in' language is the biggest overstatement… ghx's tier2
> surface is deliberately explicit: status, tool registry, report backend IDs,
> CLI/persona text, and probably tests all need updates. Ordinary work, not a
> blocker — but describe it as 'fits the existing pattern with explicit registry/
> report/policy updates,' not as nearly automatic."

**Judged and accepted (all three, none rejected).** They sharpen, not overturn, the
decision — every correction makes the case *more* honest, none reverses the verdict:

1. **License:** "zero GPL" → "**all deps usable under permissive terms**; zstd is
   dual BSD/GPLv2 with **BSD selected**, JDT is EPL-2.0 **reference-only**." Still a
   GO — nothing forces a copyleft obligation on a shell-out — but stated precisely.
2. **Feasibility:** drop "clean drop-in." The adapter mirrors `codemap.go`, but the
   effort explicitly includes the registry/report/policy list updates
   (`status.go:41`, `tool_registry.go:132`, `report.go:45`) + tests. Effort **M**,
   not trivial. Folded into ADR-0024.3 D1/D2.
3. **Microbench:** cite the vendor headline as **"120× fewer tokens (5 structural
   queries)"**, not "99%."
